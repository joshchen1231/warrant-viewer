# 權證檢視器 — 概念文件（CIM）

> 階層：CIM（概念層）｜語言：繁體中文（純業務語言，不談技術）
> 日期：2026-08-08｜狀態：初版，待使用者確認

## 1. 痛點（一句話）

投資人想用「自己的標準」在一檔標的股票的所有權證中，一次篩出候選、比較到期情境與收益率、並決定資金怎麼分配——現有券商工具只能「看」，不能「算」、不能「留歷史」、不能「換規則」。

## 2. 為什麼這個工具必須存在

- **不做的話會怎樣**：繼續在數個券商網站之間來回比對，判斷依據（例如某檔權證的隱含波動率一個月來穩不穩定）無法累積、無法量化。
- **第一個使用者**：你自己。本機單人使用，資料不出電腦（與你既有的 R 檢視器習慣一致）。

## 3. 核心能力 vs 延伸

核心（最小可移除痛點，M0/M1）：

| 編號 | 能力 |
|---|---|
| C1 | 依標的股票（代號或名稱）搜尋其對應的全部上市、上櫃權證 |
| C2 | 依自訂標準篩選：行使比例、隱含波動率、價內外程度、剩餘天數、發行券商、權證類型、認購/認售 |
| C3 | 比較表格：一次並排多檔權證的關鍵數字，可排序 |
| C4 | 單檔分析：到期損益情境圖、隱含波動率、Delta、收益率、損益平衡價 |
| C5 | 每日盤後自動收集資料並留存歷史（畫走勢圖的前提） |

延伸（標記清楚，不做進核心）：

| 編號 | 能力 | 狀態 |
|---|---|---|
| E1 | 多檔資金配置最佳化（效率前緣、建議權重） | 已納入本次範圍（M2） |
| E2 | 官方「權證資訊揭露平台」委買/委賣隱波參考值對照 | 未排入（資料為隨機取樣、格式難取） |
| E3 | 自選股清單持久化 | 未排入 |
| E4 | 匯出報告（CSV / 圖片） | 未排入 |

## 4. 角色

- **單一使用者**（投資人兼分析者）。無帳號、無多人、無權限區分。
- 發行券商不是使用者，只是資料的產生者。

## 5. 業務規則

- **R1** 權證清單必須涵蓋上市與上櫃兩個市場，且能依標的股票代號或名稱搜尋。
- **R2** 每檔權證的基本條件（行使比例、履約價、到期日、類型、發行券商、上下限等）以官方當日揭露為準。
- **R3** 隱含波動率以「權證收盤價依標準定價模型反解」計算；模型與參數慣例與官方揭露一致（無風險利率＝台灣銀行一年期定存利率）。
- **R4** 每日盤後自動收集；使用者隨時看得到「資料是哪一天」的。
- **R5** 篩選只縮小範圍、不竄改資料；系統提供建議預設值，但任何一檔權證都不會被系統隱藏。
- **R6** 每個計算數字都附定義與公式來源（可解釋，不黑箱）。
- **R7** 歷史資料只累積、不覆寫。
- **R8** 資金配置建議必須附上假設與限制說明（權證是高風險、快速衰減的短年期工具；輸出僅供研究，不構成買賣建議）。
- **R9** 資料取得失敗時必須明顯標示（缺資料的交易日不得偽裝成正常資料）。

## 6. 邊界（本工具不做什麼）

- 不做盤中/即時報價。
- 不下單、不做任何交易。
- 無帳號、不部署到公開網路（僅本機）。
- 不做手機版。
- 不涵蓋海外市場。
- 不給「買賣建議」：只提供數字、圖表與假設，判斷由使用者自己做。

## 7. 成功標準（驗收導向）

- 以台積電（2330）示範：一次列出全市場對應權證（實測目標 ≥50 檔），行使比例、隱含波動率、價內外程度排序正確，篩選條件即時生效。
- 單檔分析的隱含波動率與公開券商權證計算器「同參數」比對，誤差小於 1 個百分點。
- 每日自動收集連續運行 5 個交易日，資料日期、缺漏標示正確。
